# こんだて逆算ノート

献立から、いちばん安い買い方と使い切りまで考える買い物アプリ（プロトタイプ）。

## 使い方

`index.html` をブラウザで開くだけで動きます（インストール不要）。GitHub Pages でも公開できます。

## ログイン（デモ版）

最初にログイン画面が出ます。「新規登録」でニックネーム・メールアドレス・パスワードと、よく買い物するエリア・移動手段を登録すると、そのエリアの近くのお店（3軒）で計算します。「ゲストで試す」ならすぐに使えます（あとからアカウントを作ると、ゲストの記録を引き継げます）。

「現在地から近くのお店を探す」を押すと、ブラウザの位置情報で現在地を取り、OpenStreetMap のデータ（Overpass API、APIキー不要）から近くのスーパー2軒とドラッグストア1軒を探して、そのお店で計算します（業務スーパーなどの大容量系はお店の名前で判定）。位置情報は https のページ（GitHub Pages など）か、パソコンで index.html を直接開いたときに使えます。送るのは緯度・経度だけで、保存する位置は約100mの粗さに丸めています。お店の名前と距離は実際のデータですが、価格はサンプルです。

サーバーを使っていないため、アカウントと記録はその端末のブラウザの中だけに保存されます。ふだん使っているパスワードは使わないでください。本番では、サーバー側の認証（Firebase Authentication など）とお店のデータベースに置きかえる想定です。

## 使い方の説明（チュートリアル）

はじめてログインしたとき（ゲストも）に、使い方を6枚のスライドで紹介します。「スキップ」でいつでも閉じられ、あとから「アカウント」→「使い方（チュートリアル）を見る」で見直せます。最後の「サンプルで試す」を押すと、サンプルの献立が入った状態で始められます。

## 画面

画面の下のメニュー（かいもの・きろく・価格メモ・お店・アカウント）で切り替えます。

- **かいもの**：作りたい献立を選ぶと、近所の3店舗の価格から次のことが分かる。「1 献立をえらぶ → 2 買い方を見る → 3 買い物する → 4 家の食材」の4ステップで、1画面に1つのことだけを表示する。上のステップ表示か、画面下の「もどる／次へ」で移動する（献立はタグバーで、すべて・えらび中・じぶんの献立・主菜などに絞り込める）
  - 合計金額がいちばん安い買い方（1軒、または2軒の組み合わせ）
  - 「安い品目の数」で選んだ場合と「合計金額」で選んだ場合の差
  - 寄り道の判断：2軒目に寄ると何分よけいにかかって、いくらおトクになるか。1時間あたりの節約額が、自分で決めた基準より大きいときだけ2軒回るプランをおすすめする
  - 店ごとの買い物リスト：買ったら ✓。お店・個数・金額が違ったら「変更」、買わなかったものや、リストにないものも記録できる。「買った！記録する」で、実際に払った金額が「きろく」に残り、価格メモも更新される。記録すると献立は自動でリセットされる
  - 家にある食材：「買った！記録する」で余った食材が自動で入る（手で追加・削除も可）。次の献立では先に家の食材を使い、足りない分だけを買い物リストに出す。献立を選んでいないときは、家の食材で作れる献立を提案する
  - 使い切りチェック：残りそうな食材（家にある分も含む）と、それを使い切れる献立の提案
  - わけあい：使い切れない分を、同じ大学・寮の利用者と分けて買う（未開封のまま店頭か学内で受け渡し）
  - お店からのおすすめ：値引きの配信枠（時間帯・先着人数）を確認して取り置きできる
  - リストにないものを買ったときは、食材を一覧から選ぶか「その他」で品名を入れて記録できる
  - 献立の追加：献立名を入れて「AIで食材を入れる」を押すと、食材と分量が自動で入る（手で入力・修正も可）。追加した献立は「じぶんの献立」に保存される
- **お店の画面**：来店前の献立データから、明日の需要予測と予定在庫を比較する。売れ残りそうな食材は、値引きと献立をセットにしてアプリで配信できる。一斉に配信すると混雑するので、来店が少ない時間帯に人数を分けて配信する（配信すると「かいもの」画面の価格とおすすめに反映される）
- **きろく**：これまでの買い物の記録（実際に払った金額と、予定との差）
- **アカウント**（下のメニューの右端）：ニックネーム、よく買い物するエリアと移動手段（近くのお店と所要時間が変わる）、寄り道の基準（1時間あたりいくら以上おトクなら2軒回るか）、わけあいの範囲（同じ寮・同じ大学・使わない）、お店からのおすすめの受け取り、記録の削除、ログアウト、アカウント削除
- **価格メモ**：店ごとの価格を自分で書き換えられる（ブラウザに保存される）。「カメラで撮る」「写真をえらぶ」でレシートの写真から文字を読み取り（Tesseract.js の日本語データ、画像は端末の中だけで処理）、食材と価格を見つけて更新できる。読み取った文字は確認・修正してから反映する。レシートにお店の名前があれば、お店も自動でえらぶ。文字を貼り付けることもできる

## ファイル

- `index.html`：画面の骨組み
- `css/style.css`：デザイン
- `js/data.js`：店・食材・価格・献立のサンプルデータ
- `js/nearby.js`：現在地のまわりのお店を探す（OpenStreetMap）
- `js/auth.js`：ログイン・新規登録（デモ版）
- `js/receipt-ocr.js`：レシートの写真から文字を読み取る
- `js/app.js`：計算と描画
- `js/tutorial.js`：使い方の説明（チュートリアル）

## AIで食材を入れる機能について

「献立を追加する」→「AIの設定」に Anthropic のAPIキーを入れると、どんな献立名でもAIが食材と分量を考えます。価格表にない食材は、目安価格つきの新しい食材として追加されます。キーはそのブラウザの中だけに保存されます（ファイルには書き込まれません）。

APIキーがないときは、`js/data.js` の `DISH_DICTIONARY`（麻婆なす・豚汁・ハンバーグなど16品）から推定します。

価格・需要・在庫・来店人数・わけあいの希望人数はデモ用のサンプル値です。米と調味料は家にある前提で計算しています。
